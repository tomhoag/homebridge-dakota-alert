
# Dakota Alert Homebridge Plugin

This is a Homebridge plugin to expose alerts from the Dakota Alert RE-4k Plus wireless receiver as HomeKit motion sensors. The wireless receiver picks up motion alert signals from the Dakota Alert Directional Wireless Probe Transmitter (DAPT-4000).

The receiver has two form "C" relays that may be programmed to close when an arrival or departure detection is generated by the transmitter. Complete instructions on how to configure the receiver relays may be found in the [RE-4k Plus User Guide](https://dakotaalert.com/wp-content/uploads/RE-4k-Plus-1.pdf) under 'Advanced Setup'.

This plugin requires Homebridge running on a Raspberry Pi, as it reads GPIO pins via the Linux sysfs interface.

## Installation

Install from GitHub on the Raspberry Pi where Homebridge is running:

```
cd /var/lib/homebridge
sudo env PATH="/opt/homebridge/bin:$PATH" npm install tomhoag/homebridge-dakota-alert
```

Then restart Homebridge.

## Hardware Setup

Connect the ground and NO (normally open) contacts of each receiver relay to a ground pin and a GPIO pin on the Raspberry Pi. The Homebridge user must be a member of the `gpio` group.

## Configuration

### Using the Homebridge UI

Add the "Dakota Alert" platform and configure each alert with a name and GPIO pin number.

### Editing config.json

Add to the `platforms` array:

```json
{
  "platform": "DakotaAlert",
  "name": "Dakota Alert",
  "alerts": [
    {
      "label": "Arrival",
      "pin": 4
    },
    {
      "label": "Departure",
      "pin": 3
    }
  ]
}
```

| Field | Description |
|---|---|
| `platform` | Must be `"DakotaAlert"` |
| `name` | Display name for the platform |
| `alerts` | Array of 1-2 alert objects |
| `alerts[].label` | Name for the motion sensor (e.g. "Arrival") |
| `alerts[].pin` | Raspberry Pi GPIO pin number (0-27) |
